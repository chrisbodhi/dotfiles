# Shortcuts

- `ga` for `git add`
- `gco` for `git checkout`
- `gc` for `git commit`
- `gs` for `git status`
- `ggpush` for pushing the current branch to the remote repository

# Preferred utilities

- Use `fd` instead of `find`
  - Use the flag `-td` to search for directories
  - Use the flag `-H` to search for hidden files
  - Use the flag `--no-ignore` to search for files ignored by `.gitignore`
- Use `rg` instead of `grep`
- Use `bat` instead of `cat`
